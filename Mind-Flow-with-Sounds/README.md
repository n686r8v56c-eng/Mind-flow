Mind Flow 음원 포함 실행본

1. 전체 폴더를 GitHub 저장소에 업로드합니다.
2. 터미널: npm install
3. 터미널: npm run dev
4. 포트 5173에서 실행합니다.

기본 음원 17개는 public/audio 아래에 포함되어 있습니다. 새 음원 추가는 앱에서 할 수 있으나 기존 앱 내 업로드 음원은 브라우저 저장소에 기록되어 기기 사이 동기화되지 않습니다.
기본 음원은 폴더가 아니라 앱의 14개 버튼으로 표시됩니다.
화면 잠금 및 백그라운드 타이머는 iOS Safari에서 완전한 보장이 어려워 실기기 테스트가 필요합니다.
MP3 출처별 라이선스를 사용자가 확인해야 합니다.
